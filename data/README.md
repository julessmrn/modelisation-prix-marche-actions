# Données

Le fichier `finance_dataset_25000_with_qualitative.csv` a été fourni dans le cadre du cours et n'est pas redistribué dans ce dépôt.

Pour relancer le notebook, placer le fichier ici : `data/finance_dataset_25000_with_qualitative.csv`.

- **25 000 entreprises** cotées, une ligne par entreprise.
- **Cible :** `market_price`, le prix de marché.
- **Variables explicatives :**
  - macroéconomiques : inflation, taux d'intérêt, croissance, chômage, indice de volatilité ;
  - financières : chiffre d'affaires, dette, actifs, capitaux propres, flux de trésorerie, ROA, ROE, EPS, P/E ratio, bêta, rendement du dividende ;
  - de marché : momentum à 3, 6 et 12 mois, volume, liquidité, fourchette bid-ask ;
  - de risque : VaR 95 %, expected shortfall, spread de crédit ;
  - qualitatives : secteur, notation, région, place de cotation, qualité de l'audit.
- Environ 8 % de valeurs manquantes sur chaque variable.
